## Work with the project

Browse the [GoPMgr source repository](https://github.com/draconianneocoder-cpu/GoPMgr) and read its current contribution and build instructions before proposing a change.

## Report a general problem

Use the [repository issue tracker](https://github.com/draconianneocoder-cpu/GoPMgr/issues) for non-sensitive bugs. Include the exact version or source commit, operating system, steps and expected/observed result. Use a fictional minimal example.

Never attach live project databases, recovery codes, passwords, private certificates or unredacted logs. For security-sensitive findings, read [security reporting](../security/) first; a public issue is not a private disclosure channel.
