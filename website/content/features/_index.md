All capabilities below describe the reviewed development source. They are not a promise that the historical alpha contains the same implementation or has passed native qualification.

## Scheduling and baselines

**Development:** model task dependencies, use business calendars and capture baselines. Read the [scheduling guide](https://github.com/draconianneocoder-cpu/GoPMgr/blob/1ca5ffaed63446b35b197a6083d03899c0143f55/docs/user-guide.md#stakeholders-timeline-budget-and-cost-control). This site makes no verified task-count or performance claim.

## Costs and earned value

**Development:** track budgets and committed costs, then review portfolio rollups with explicit coverage and currency rules. GoPMgr has no foreign-exchange conversion. [Read the portfolio contract](https://github.com/draconianneocoder-cpu/GoPMgr/blob/1ca5ffaed63446b35b197a6083d03899c0143f55/docs/user-guide.md#portfolio-and-dashboard).

## Charts, documents and exports

**Development:** work with project charts, documents and export formats. PDF/A metadata precedes the final PAdES signing mutation; actual trust depends on certificates and validation. [Read report and signing guidance](https://github.com/draconianneocoder-cpu/GoPMgr/blob/1ca5ffaed63446b35b197a6083d03899c0143f55/docs/user-guide.md#pdf-signing).

## Local data protection

**Development:** local accounts, encrypted project databases and one-time recovery codes have distinct limits. They do not replace operating-system security or independent backups. [Understand the security model](../security/).
