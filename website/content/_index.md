## A workspace for project decisions

GoPMgr brings scheduling, cost control and reporting into a local-first desktop application. The source is under active development. The published installers are an older alpha, released for limited evaluation.

### Plan the work

Explore critical-path scheduling, calendars and baselines. [See development capabilities](features/).

### Understand the cost

Read about project budgets, committed costs and earned value in the [canonical user guide](https://github.com/draconianneocoder-cpu/GoPMgr/blob/fc70b50d41e5e842b541e88686604ce26221d4c3/docs/user-guide.md#portfolio-and-dashboard).

### Start with the documentation

Read the documentation before choosing an installer. [Get started](docs/getting-started/) or read about the [evaluation release and its limits](downloads/).

## Local-first, with clear limits

The desktop application keeps project data on your machine. This website is a static guide, not an online GoPMgr workspace. It contains no project uploads or account portal. GitHub hosting has its own request logging policy; the site adds no visitor analytics.
