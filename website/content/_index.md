## A workspace for project decisions

GoPMgr brings scheduling, cost control and reporting into a local-first desktop application. The current source is under development; published installers are an older, limited engineering-validation alpha.

### Plan the work

Explore critical-path scheduling, calendars and baselines. [See development capabilities](features/).

### Understand the cost

Read about project budgets, committed costs and earned value in the [canonical user guide](https://github.com/draconianneocoder-cpu/GoPMgr/blob/1ca5ffaed63446b35b197a6083d03899c0143f55/docs/user-guide.md#portfolio-and-dashboard).

### Review and share

Find the documentation before choosing an installer. [Get started](docs/getting-started/) or review the [evaluation release and trust limitations](downloads/).

## Local-first, with clear limits

The desktop application keeps project data on your machine. This website is a static guide, not an online GoPMgr workspace. It contains no project uploads or account portal. GitHub hosting has its own request logging policy; the site adds no visitor analytics.
