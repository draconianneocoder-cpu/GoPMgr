## Development source

Local project storage, scheduling, earned-value analysis, reports and exports exist in the reviewed source. See [capabilities](../features/) for applicability, not native-support guarantees.

## Current priorities

The canonical roadmap prioritizes dependable save/recovery workflows, native installation and upgrade evidence, trustworthy distribution, and keyboard/assistive-technology coverage.

## Planned, not measured

High-scale scheduling is a direction, not an achieved performance benchmark. No dates, user counts or scalability numbers on this site are promises.

## Historical decisions

DuckDB was retired in favor of Go-native analytics. The DataFusion spike concluded without adoption. This website does not advertise either as an integrated analytics engine.
